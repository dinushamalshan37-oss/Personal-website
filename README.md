# Dinusha Malshan Portfolio

A premium personal portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Scripts

- `npm run dev` — run the app in development mode
- `npm run build` — production build
- `npm run start` — start the production server
- `npm run lint` — run ESLint

## Environment

Copy `.env.example` to `.env.local` and replace placeholder values before enabling Firebase-backed features.
